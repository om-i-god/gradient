# Round 3: more sound, more visual options, better themes

## Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task by task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the new voices and the `echo_type`/`character` params. Add
`trails`, `detail` and `reactivity` and four new themes. Refine all 24
existing themes' rendering and reactions, keeping a `classic` setting that
reproduces today.

**Architecture:**
- **Kit (`lib/visuals.lua`)** gains `K.trail` (a fade-time scale),
  `K.detail` (`"classic"`, `"fine"` or `"dense"`), `K.react` (a reaction
  scale) and the sub-pixel helpers `K.put_sub` / `K.line_sub`. Themes branch
  on `K.detail == "classic"` to keep their old drawing.
- **Engine:** new SynthDefs, a new `echo_type` swap following `verb_type`,
  and a `character` mode on the master.
- **`lib/timbre.lua`:** gains an appended draw for the new voices.

**Tech stack:** Lua 5.3 (norns); tests also run on 5.4. SuperCollider
3.13-dev on the norns.

**Spec:** `docs/superpowers/specs/2026-11-08-round3-design.md`

## Global constraints

- **Add, never replace for sound:** existing params, IDs, option orders and
  voices are unchanged, and new options are appended.
- **Visual improvement:**
  - Keep each theme's composition and elements, and which part answers
    where.
  - Rendering and reaction strength may improve at `detail` = fine, the
    default.
  - `detail` = classic must reproduce the pre-pass frames exactly (a
    fixture hash).
- **Visual bounds** at the defaults, in every scenario: lit ≤ 0.40, live >
  0.04, silence > 0.01; frame change ≤ 0.7; ≤ 12 pixels at level 15; ≤ 1200
  ops; no NaN.
  - The extremes (`trails` 0/100, `reactivity` 0/100, `detail` dense) are
    tested on `peak` and `mid`, one param at a time.
- **Reaction thresholds** at fine: part ≥ 0.0045, band ≥ 0.015.
- **Lua 5.3:** every test passes on 5.3 (at
  `<path to a Lua 5.3 binary>`)
  and on 5.4.
- **SuperCollider safety:**
  - No `t_foo` argument with the same name as a `foo` argument.
  - Parenthesise compound expressions.
  - Clamp `sqrt` input with `.max(<positive literal>)`, which
    `test/unit_engine.lua` enforces. Keep `log`, `pow` and division away
    from 0.
  - No `Mix.ar([..])`.
- **Levels:** each new voice is within ±4 dB of the part's first fixed type.
- **CPU and memory:** CPU on a norns at peak with the heaviest choices stays
  under about 45%. Real-time memory is about 8 MB, so delay lines stay short.
- **Repo hygiene:** load modules with `include()`, never `require`. No
  device names or IPs in the repo.

## Review focus

1. **classic after the pass.** Every existing theme's classic hashes match
   the fixtures. Pinned in R1 (the fixture test) and checked in every
   improvement task.
2. **Swapping `echo_type` or `character` mid-play.** There's no click, at
   most one extra node at a time, and the remembered settings survive.
   Pinned in R10 (`fx_swap.scd`).
3. **An old PSET.** A PSET without the new params loads with the defaults:
   echo dub, character clean, trails 50, detail fine, reactivity 50. Pinned
   in R11 (sim).
4. **`trails` at 100 on a busy peak.** Lit stays ≤ 0.40 because the kit
   clamps it. Pinned in R1 (the extremes test).
5. **`reactivity` at 0.** Themes still move and pulse, without dead frames.
   Pinned in R1 (the extremes test, with the silence-moves check).

### Task R1: Kit params, sub-pixel helpers, the classic fixtures, raised thresholds

**Files:**
- Modify: `lib/visuals.lua`. Add `K.trail`, `K.detail`, `K.react`,
  `K.put_sub` and `K.line_sub`, plus a trails clamp. Wire them to the new
  visual params through `VIS.set_trails(v)`, `VIS.set_detail(name)` and
  `VIS.set_react(v)`.
- Modify: `gradient.lua`. Add the params `vis_trails` (0–100, default 50),
  `vis_detail` (classic/fine/dense, default fine) and `vis_react` (0–100,
  default 50) to the visuals group, and set their actions.
- Create: `test/fixtures/classic_frames.lua`. It holds a hash per theme ×
  scenario, generated from the current code **before** any theme change.
- Modify: `test/unit_visuals.lua`:
  - the classic-hash test;
  - the param-direction tests;
  - the extremes tests;
  - raise the thresholds at fine to 0.0045 (part) and 0.015 (band).

**Interfaces (produces):**
- `K.trail` is a number: 1 at 50, about 0.4 at 0 and about 2.5 at 100.
  Themes multiply their fade tau by it.
- `K.detail` is a string.
- `K.react` is 1 at 50, 0.4 at 0 and 1.8 at 100. Themes multiply their
  reaction strength by it.
- `K.put_sub(level, x, y, w, h)` splits the level between `floor(x)` and
  `floor(x)+1` by the fractional part. The same applies to y when it is
  fractional.
- `K.line_sub(level, x1, y1, x2, y2)` does the same, for lines.
- **The trails clamp:** if a theme's lit ratio over the last 10 frames
  passes 0.38, the kit lowers the effective `K.trail` toward 1. It does
  this in `physics`, so it applies to every theme.

**Steps:**

- [ ] **Step 1: Generate the classic fixture** from the current code. Hash
  the raster buffer (a cheap FNV over the levels) at frames 60, 120, 180
  and 240 for every theme × {silence, mid, peak, kickless}. Commit it with
  a test that passes now.
- [ ] **Step 2: Write the failing tests.**
  - `vis_detail` = classic matches the fixture. This passes now, because
    classic is today.
  - `trails` at 100 gives more lit-frames persistence than at 0 on `peak`
    (it fails until the themes read it; for now assert only on the kit's
    value).
  - The extremes keep the bounds on `peak` and `mid`.
  - The raised thresholds at fine. Expected: they fail for most themes, and
    tasks R3–R8 fix that.
- [ ] **Step 3: Implement the kit and the params.**
  - With every param at its default and `detail` = classic, nothing changes.
  - Themes don't read the new fields yet.
- [ ] **Step 4: Run the tests.**
  - The classic, kit and extremes tests pass.
  - Only the raised-threshold checks fail.
  - Record the failure table in the report: theme × part and band at
    0.0045 and 0.015.
- [ ] **Step 5: Commit.** `git commit -m "visuals: trails/detail/reactivity params, sub-pixel helpers, classic fixtures, raised bars"`
